# Исходные данные

Создайте папку `data/` в корне проекта и положите в неё исходные таблицы.

Для повторного запуска нужны четыре учебных файла:

- school_q3_2025.xlsx — листы users и lessons;
- payments_2025_07.xlsx;
- payments_2025_08.xlsx;
- payments_2025_09.xlsx.

Используйте соответствующие выгрузки из задания Т-Академии, убрав UUID из названия. Оригинальные учебные таблицы не входят в публичную папку. Их добавление на GitHub требует права на распространение.
