# Аналитика онлайн-школы

Учебный проект по продуктовой аналитике на основе задания Т-Академии. Разбираю данные за Q3 2025: от качества выгрузок до сравнения каналов привлечения.

## Что сделано

- Объединены три выгрузки с разными названиями колонок и форматами сумм.
- Проверены соединения платежей с пользователями; отдельно выделены платежи без совпадения в справочнике.
- Рассчитаны MAU, платящие, выручка, ARPU, ARPPU и доля возвратов.
- Сравнены каналы и сформулирована гипотеза для дальнейшей проверки.

## Результаты

В данных 4 000 пользователей и 883 платежа. По правилам кейса 12 платежей без пользователя исключены. Выручка по успешным платежам известных пользователей — 2 381 160 ₽, платящих — 587.

В сентябре Organic лидирует по ARPU, Referral — по ARPPU. Самая высокая доля возвратов у Blogger. Это результаты учебного анализа; причинное влияние каналов и прибыль здесь не измерены.

## Запуск

Установить зависимости: `pip install -r requirements.txt`. Положить исходные Excel в `data/` по [инструкции](DATA.md). Открыть ноутбук из папки проекта и выполнить Restart Kernel → Run All.

В репозиторий включены выполненные результаты. Исходные таблицы курса не распространяются этим пакетом, поэтому для повторного запуска их нужно получить отдельно.

## Ограничения

Платящие и MAU считаются по разным событиям: payers/MAU не является конверсией одной когорты. Нет данных о расходах, LTV и причинах возвратов. Выручка определена как сумма успешных платежей по условию задания и не равна прибыли.

Основа кода — сохранённая версия выполненного учебного задания. При подготовке к публикации с AI сокращены условия, удалены неиспользуемая загрузка и повторяющиеся пояснения, обновлены пути. Расчётная логика сохранена.
